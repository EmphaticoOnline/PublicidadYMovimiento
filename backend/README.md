# Backend PublicidadYMovimiento

Este proyecto es un backend básico en Node.js y Express para interactuar con la base de datos PostgreSQL emphasys.

## Características
- Conexión a PostgreSQL
- Rutas CRUD de ejemplo
- Listo para integrarse con el frontend

## Instalación
1. Instala las dependencias:
   ```powershell
   cd backend
   npm install
   ```
2. Configura las variables de entorno en un archivo `.env`.

## Uso
1. Inicia el servidor:
   ```powershell
   npm start
   ```
2. Accede a los endpoints definidos en `src/routes`.

## Personalización
- Modifica los modelos y rutas según tus necesidades.

## Estructura
- `src/` Código fuente principal
- `.env` Variables de entorno
- `README.md` Documentación
